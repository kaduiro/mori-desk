## Artwork

The upstream project's artwork is not distributed with Mori Desk. The source
assembler excludes upstream `assets/`, `themes/`, and media files. Original Mori
sprout artwork is generated by `scripts/generate-mori-assets.js`, without reading
or tracing upstream images. The generator, Mori theme metadata, and generated
Mori artwork are MIT licensed; see `themes/mori/LICENSE`. This separate artwork
license does not change the application code license.

The upstream `NOTICE.md` is preserved for attribution and provenance. Its
references to upstream artwork describe the upstream distribution; those assets

Anthropic, OpenAI, or the upstream project is asserted.
