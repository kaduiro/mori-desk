# Mori Desk contributor instructions

This repository is a pinned source derivative of Clawd on Desk. It contains an
upstream lock, a patch, and new source files. The application is assembled into
`.runtime/` by `npm run setup`; `.runtime/` and `.upstream/` are generated and
must not be committed. Do not edit generated runtime files as the final source
of a change: export existing-file changes to `patches/mori.patch` and new files
to `overlay/`, then verify reconstruction.

Before changing inherited runtime behavior, read `.runtime/AGENTS.md` from the
pinned upstream source and the relevant owner modules. Follow the user's task
authorization; ordinary reversible fixes do not require a separate approval.

## Product boundaries

- Preserve upstream AGPL and attribution. Never import the separately restricted
  upstream artwork into the tree or Git history. Mori artwork is generated by
  `overlay/scripts/generate-mori-assets.js` under its stated MIT license.
- Keep the Mori application identity, data directory, and manual update owner.
  Do not restore upstream release downloads, theme catalogue downloads, or
  `clawd://` registration in this preview.
- Default startup is browser-only. CLI integrations require `--enable-cli` and
  explicit settings. Do not silently migrate shared Claude/Codex/Clawd files.
- Browser metadata belongs to `browser-session-store.js`, not the CLI session
  reducer. Merge only at the local HUD/browser panel boundary.
- Browser-only HTTP must not identify itself as a native Clawd hook server.
  Existing native Origin/Host/Content-Type protections stay unchanged in CLI mode.
- Preserve HMAC mutual authentication, exact Origin/Host checks, safeStorage
  failure behavior, strict message schemas, durable receipt ACK, per-tab identity,
  and focus-before-ack race protection. Browser status detection remains based
  on structural DOM signals. The user-authorized local identification feature
  may read an existing conversation title and an excerpt of the latest submitted
  user request, each limited to 160 UTF-16 code units. Keep this display metadata
  bound to the verified current document/conversation and within the paired local
  browser store/HUD boundary. Never collect composer drafts, assistant answers,
  conversation transcripts, HTML, cookies, or API keys. Diagnostics remain
  categories/counts only; do not send identification text to external consumers.
- DOM uncertainty, disconnects, closed tabs, and stale observations are not
  normal completion. A new turn must not clear an older unread receipt.

## Verification and delivery

Use Node 24.18+ within the 24.x line. `npm test` at this repository root runs
the browser/Mori regression suite. Inspect the individual test assertions and
the actual completion status; a test-file wrapper alone is not proof that its
subtests ran. Rebuild the runtime after source changes before final validation.

Native Windows/macOS, installed Chrome, provider DOM, signatures/notarization,
and installer behavior require their actual environments. Synthetic fixtures
and Linux GUI smoke tests must be labelled as such. Do not claim a binary is
available unless it was actually built and attached/published.

The source setup is transactional: preserve the previous usable runtime on
failure. Delete only owned staging/backup paths, never arbitrary user files or
CLI configuration. Do not bypass PowerShell execution policy, browser policy,
certificate validation, or OS application trust checks.
