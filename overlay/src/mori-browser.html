Chrome と接続

  1. Chrome の chrome://extensions を開き、デベロッパーモードをオンにします。
  2. 「パッケージ化されていない拡張機能を読み込む」で、下のボタンから開くフォルダーを選びます。
  3. 接続コードを作成・コピーし、Chrome の「MORI Browser Bridge（プレビュー）」に貼り付けて「接続する」を押します。
  4. ChatGPT / Claude の会話タブを開きます。上のサービスごとの確認状況に、ページの応答と会話の識別状況を表示します。
