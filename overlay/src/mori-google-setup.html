MORI DESK

個人 Google Cloud の準備

Calendar と Gmail を自分の Google Cloud プロジェクトで試す手順です。設定には Google アカウントが必要です。

1. プロジェクトと API

Google Cloud Console を開く。自分が管理するプロジェクトを選ぶか作成し、Gmail API と Google Calendar API だけを有効にします。請求先の有無と実際の利用枠を Console で確認してください。Mori Desk は Cloud 管理権限を要求しません。

2. Google Auth Platform

「ブランディング」「対象」「データアクセス」を確認し、Desktop アプリの OAuth クライアントを Calendar 用と Gmail 用に作ります。Gmail には gmail.readonly、Calendar には calendar.events.readonly と calendar.calendarlist.readonly だけを設定します。OAuth クライアントの作成、規約への同意は本人が Console で行ってください。

External / Testing は許可したテストユーザーだけが接続でき、Gmail 権限の更新トークンは通常7日で失効します。継続利用や不特定多数への配布条件とは区別してください。Workspace アカウントは組織の管理者設定で拒否される場合があります。

3. Mori Desk に取り込む

Calendar の設定画面と受信メール HUD の設定から、それぞれの Desktop OAuth JSON を選びます。Google の同意を自分のブラウザーで行い、接続先アカウント、予定と未読、手動更新を確認してください。JSON や認可コード、トークンをチャット・リポジトリ・Web サイトに貼らないでください。

このアプリが確認できるのは JSON の形式と Google API で実際に接続できたアカウントです。JSON だけで Cloud プロジェクトの所有者や請求状態は証明できません。

4. 利用枠を確かめる

実効枠と請求条件はプロジェクトごとに確認します。Mori Desk の Gmail 同期は通常5分間隔で、更新ボタンには連打防止があります。無料利用は保証されません。
