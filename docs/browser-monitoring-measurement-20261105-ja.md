## 実行する場所

1. 常用側のソースと runtime を再構築・照合する。
2. 常用側で `npm run prepare:development` を実行し、表示された `.development/workspace-<UUID>` へ移動する。既存のコピーは上書きしない。
3. そのコピーで `npm run measure:monitoring -- --regression` を実行する。実 Chrome を使う検証は、同じコピーで `npm run measure:monitoring:native -- --smoke` を使う。

ネイティブ計測の準備は所有情報のある開発コピーでのみ進む。通常の Mori プロフィールの起動は開発コピーでは拒否される。計測用 runtime と拡張機能は通常利用側へ自動反映しない。
