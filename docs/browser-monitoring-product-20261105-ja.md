# ブラウザー監視の製品実装と検証範囲

2026-11-05。拡張機能 `0.1.15` の製品コードを、Calendar・Gmail HUD と起動分離の変更から独立させた記録。計測用の採取器、生ログ、個人のブラウザー情報はこのブランチに含めない。

## 実装の境界

- ChatGPT と Claude の現在の文書と会話を構造的な DOM 情報で確認し、生成中と結果確認の状態をローカルの HMAC 認証済み接続へ送る。所属が確かでない画面は保留し、入力中の文、回答本文、会話履歴を採取しない。
- 保存済み通知の ACK とタブへの移動は、送信元の文書・タブと通知番号を照合する。監視が途切れた場合は結果未確認の記録を保持し、後続の正常通信だけで古い未確認を消さない。
- ブラウザー連携画面と HUD は、接続状態、監視中の件数、保留理由、保存済み通知の同期状態を別々に示す。表示用の短いタイトル・送信済み依頼の抜粋は、確認された現在の会話に限る。

## 確認と残件

このブランチの `npm test` は合成 fixture とローカル WebSocket を含む516件で、514件成功・失敗0件・skip1件・todo1件だった。固定上流から runtime を再構築し、`npm run doctor` で次回起動の `source_check_passes (source_matches)` を確認した。これらは実 Chrome の DOM、全画面遷移、OS ログイン後の起動や配布バイナリを証明しない。実サービスの受入は、別の計測用作業ツリーに保管した証跡をプライバシー確認のうえ評価する。
